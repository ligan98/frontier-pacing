# frontier-pacing

Interactive companion pages for the frontier-pacing papers by Li Gan: ceilings, allocation, labs and agreements.
Chinese pages are at the top level (`index.html`); English pages are in `en/` (`en/index.html`).
Each page is one self-contained HTML file.

前沿人工智能速度系列论文的交互式配套页面（中文），作者甘犁。每个页面是一个独立的 HTML 文件，从 `index.html` 打开。
